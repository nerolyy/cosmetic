# 🚀 Быстрый старт - Установка базы данных

Этот проект включает автоматический скрипт установки для быстрого запуска интернет-магазина косметики.

## 📋 Требования

- PHP 7.4 или выше
- MySQL/MariaDB 5.7 или выше
- MAMP/XAMPP/WAMP (или другой локальный сервер)

## 🔧 Установка

### Шаг 1: Настройка базы данных

Откройте файл `config.php` и проверьте настройки подключения к базе данных:

```php
$db_host = 'localhost';
$db_name = 'cosmetic_shop';
$db_user = 'root';
$db_pass = 'root';
$db_port = 8889; // Для MAMP обычно 8889, для XAMPP - 3306
```

### Шаг 2: Запуск установки

1. Откройте в браузере: `http://localhost:8888/cosmetic/install.php`
2. Нажмите кнопку **"Начать установку"**
3. Дождитесь завершения установки

### Шаг 3: Готово!

После успешной установки вы получите:

- ✅ База данных `cosmetic_shop` создана
- ✅ Все таблицы созданы и настроены
- ✅ Данные из `data.sql` импортированы (если файл существует)

## ⚠️ Безопасность

**ВАЖНО:** После установки обязательно удалите или переименуйте файл `install.php` в целях безопасности!

```bash
# Удалить файл
rm install.php

# Или переименовать
mv install.php install.php.bak
```

## 📁 Что создается при установке

### Таблицы базы данных:
- `users` - Пользователи
- `categories` - Категории товаров
- `brands` - Бренды
- `products` - Товары
- `cart` - Корзина
- `favorites` - Избранное
- `orders` - Заказы
- `order_items` - Элементы заказов
- `shops` - Магазины
- `user_addresses` - Адреса пользователей
- `promo_codes` - Промокоды
- `promo_code_uses` - Использования промокодов
- `brand_favorites` - Избранные бренды

### Импорт данных:
- Если в корне проекта есть файл `data.sql`, он будет автоматически импортирован
- Для создания `data.sql` экспортируйте вашу базу данных через phpMyAdmin

## 🔄 Повторная установка

Скрипт установки безопасен для повторного запуска:
- Существующие таблицы не будут пересозданы
- Данные из `data.sql` импортируются при каждом запуске (используйте `ON DUPLICATE KEY UPDATE` в SQL)

## 🐛 Решение проблем

### Ошибка подключения к базе данных

1. Проверьте, запущен ли MySQL сервер
2. Проверьте настройки в `config.php`
3. Убедитесь, что порт указан правильно (MAMP: 8889, XAMPP: 3306)

### Ошибка "Access denied"

Убедитесь, что пользователь базы данных имеет права на создание баз данных и таблиц.

### Файл install.php не открывается

1. Проверьте, что веб-сервер запущен
2. Проверьте путь в адресной строке браузера
3. Убедитесь, что файл находится в корне проекта

## 📞 Поддержка

Если возникли проблемы с установкой, проверьте:
1. Логи ошибок PHP
2. Логи MySQL
3. Права доступа к файлам и папкам
